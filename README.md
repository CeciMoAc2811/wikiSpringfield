## Descripción

Wiki Springfield es un sitio web estático que sirve como mini enciclopedia para los personajes de Los Simpson. Contiene una página principal con enlaces a perfiles individuales y páginas de contenido con información estructurada y diseño claro.

## Características principales

- Diseño moderno y responsive con Bootstrap
- Navegación entre páginas de personajes
- Secciones con contenido organizado en tarjetas y tablas
- Formulario de registro de ejemplo
- Estilo visual consistente en todas las páginas

## Tecnologías utilizadas

- 🌐 HTML
- 🎨 CSS
- 📦 Bootstrap

## Instalación

1. Clona el repositorio o copia los archivos al directorio de tu servidor local.
2. Asegúrate de que la estructura de carpetas se mantenga:
   - `index.html`
   - `pages/homero.html`
   - `pages/familiaSimpson.html`
   - `CSS/bootstrap.min.css`
   - `CSS/styles.css`
   - `img/`
3. Abre `index.html` en tu navegador o sirve el proyecto desde un servidor local.

## Uso

- Abre `index.html` para ver la página de inicio.
- Usa el menú de navegación para acceder a las páginas de perfil de los personajes.
- Revisa la sección de registro en la página de la familia Simpson.
